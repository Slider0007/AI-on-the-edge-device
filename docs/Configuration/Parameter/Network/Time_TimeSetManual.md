# Parameter: Set Time

|                   | WebUI               | REST API
|:---               |:---                 |:----
| Parameter Name    | Set Time            | timesetmanual
| Default Value     | empty               | empty


## Description

Set device time manually


!!! Note
    Manual setting is only possible if NTP time sync service is disabled.<br>
    Syntax: YYYY-MM-DDTHH:SS:MM
