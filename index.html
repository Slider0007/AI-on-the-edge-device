AI-on-the-Edge Device [SLFork]

Web Installer / Console

This page provides a web installer and serial console for AI-on-the-Edge Device [SLFork] - A smart and efficient edge-AI application for meter digitization, designed for ESP32 and ESP32-S3 hardware. Additional documentation is available in the GitHub repository.

GitHub Repository: github.com/slider0007/AI-on-the-edge-device
Firmware: v17.3.0-SLFork

HowTo

  1. Preconditions:
    • Supported hardware with an empty, FAT-formatted SD card inserted into the SD card slot.
    • Download the matching firmware ZIP file for your device and the version listed above from the GitHub release page.
  2. Enter bootloader mode: Press and hold the "BOOT" or "IO0" button (or connect the "GPIO0"/"IO0" pin to GND if no button is available), then reset the device by pressing the "RESET" button or power-cycling it.
  3. Install firmware: Select your device, connect to it, and click "Install Device" to flash the firmware.
  4. Power cycle: After installation is complete, perform a full power cycle of the device.
  5. Configure Wi-Fi: Reconnect to the device and configure its Wi-Fi connection ("Connect to Wi-Fi").
    Note: This step can be skipped for boards with ethernet interface
  6. Access the device: Once connected to network, visit the device via the provided link ("Visit device").
  7. Prepare SD card content: Upload the downloaded firmware ZIP file to the device using its provisioning web interface.
  8. Finalize installation: Reboot the device. Wait for installation to complete, then refresh your browser.
    Note: To view console logs or monitor installation progress, switch back to the web installer page and open "Logs & Console".
  9. Run initial setup wizard: Follow the on-screen wizard to create a reference image, alignment marker and number sequences.
