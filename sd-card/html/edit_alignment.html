🎯Alignment Marker
CLICK HERE for usage info

The two alignment marker are required to correct possible small misalignments of the image position. The possible misalignment is determined by an alignment algorithm, which works according to the principle of SAD (sum of absolute differences). In a defined search window (Parameter: Search Field X / Y), the algorithm attempts to match the image pattern of the alignment marker image (Marker 1 and Marker 2) as congruently as possible. The derived correction factors are applied to the image for an orientation correction (rotation around the image center and / or linear shift).
The marker size should only be as large as necessary to depict a clean, high-contrast edge or contour. (Tip: The smaller the marker area, the faster the processing).
The histogram can be used to find image sections with high contrast or only to better evaluate the already marked areas.

Select a marker from the dropdown, define its area by dragging the mouse or entering coordinates, and click Update Marker. Once both are set, click Save And Apply to activate the changes immediately without a reboot.
