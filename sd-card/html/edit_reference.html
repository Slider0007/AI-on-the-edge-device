📸Reference Image
CLICK HERE for usage info

The reference image serves as the visual base for defining markers and ROIs; it provides feedback during setup but is not used in live processing. Click Create New Image to capture one using your current settings, or use Update Image to refresh it.
For reliable evaluation, ensure the image is horizontally aligned. Use the 'Image Rotation' parameter to pre-rotate the image, which allows the alignment algorithm to focus solely on correcting minor shifts.

Once satisfied, click Save And Apply to activate your configuration immediately without a reboot.
